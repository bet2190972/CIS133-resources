# CIS133 Resources

## HTML Resource

[W3Schools HTML Tutorial](https://www.w3schools.com/html/)

I chose this html because its html lessons are they easy to follow and includes examples that show how the code works. The interactive examples are useful for beginners because they allow you to see the results of the HTML code while learning.

## CSS Resource 

[CSS-Tricks](https://css-tricks.com/)

I chose this css resource because it provides practical explanations and examples for using CSS to design and organize webpages. It is especially useful for learning about layouts, styling, and techniques that can be applied to real websites.
